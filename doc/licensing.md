# DiegeticAmbience source licensing

Every source DiegeticAmbience draws sound from, and the basis for using it: the author granted permission, or the addon's license permits it. The readme Credits section derives from this record.

## Permission

Each author gave permission for my S.T.A.L.K.E.R. mods, and each grant records where and when the author gave it (Discord handle and date).
Freely licensed sources (Public Domain, Creative Commons) need no grant.

## Distribution

Every source above carries a free license or the author's permission. The readme credits each author, and the build includes nothing without a license or the author's consent.
